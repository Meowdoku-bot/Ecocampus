# EcoCampus

A mobile-first frontend project by **GhxstOSINT** for the Smart Campus & Student Life problem statement.

## Problem
Sustainability challenges and eco points.

## Run locally
Open `index.html` in a browser. No build tools or backend are required.

## Deploy on GitHub Pages
1. Create a repository named `ecocampus`.
2. Upload the files in this folder (`index.html` and `README.md`) to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Your live URL will be `https://ghxstosint.github.io/ecocampus/` (assuming the GitHub username is `ghxstosint`; adjust if needed).

## Evaluation checklist
- [ ] Code quality: readable functions and semantic HTML
- [ ] Security: no secrets, safe text rendering, no external data collection
- [ ] Efficiency: lightweight, no framework/runtime dependencies
- [ ] Testing: verify search, feature buttons, mobile layout, and reset
- [ ] Accessibility: keyboard focus, labels, live status region
- [ ] Problem alignment: explain the campus problem and user benefit

## Scope
This is a frontend demo. Data and interactions are local/simulated; it is not connected to real campus systems.
